4. Sprachausgabe und externe Dienste

Die Sprachausgabe (Text-to-Speech) funktioniert je nach Gerät auf zwei Wegen: auf dem Desktop über das Modell Supertonic-3, auf Mobilgeräten (Android und iOS) über die in Browser und Betriebssystem eingebaute Sprachausgabe.

Desktop: Supertonic-3

Die Sprachsynthese verwendet das Supertonic-3-Modell und wird lokal im Browser ausgeführt. Die ONNX-Modelle und Konfigurationsdateien werden von Hugging Face (huggingface.co) geladen; das Stimmprofil M1.json wird ebenfalls von dort abgerufen. Das JavaScript-Modul ONNX Runtime Web wird von unpkg.com geladen. Beim ersten Spielstart kann dadurch ein größerer Download anfallen. ONNX-Modellantworten werden in der Cache API des Browsers gespeichert, damit sie bei späteren Aufrufen wiederverwendet werden können. Das Stimmprofil wird vom Anwendungscode nicht in diesem Cache gespeichert.

Der vorzulesende Text wird dabei nicht an Hugging Face, unpkg oder einen externen Sprachsynthese-Dienst gesendet. Die Sprachausgabe wird im Browser erzeugt und abgespielt. Beim Abruf der Ressourcen übermitteln Browser technisch notwendige Verbindungsdaten, insbesondere die IP-Adresse und angeforderte URL, an die jeweiligen Anbieter. Für deren Verarbeitung gelten zusätzlich deren Datenschutzinformationen und Bedingungen.

Mobilgeräte: eingebaute Sprachausgabe

Auf Mobilgeräten nutzt Werwolf die Web Speech API (speechSynthesis) deines Browsers. Dabei werden keine Modelle von Hugging Face oder unpkg geladen. Welche Stimmen zur Verfügung stehen, bestimmt dein Gerät bzw. dein Browser. Wir wählen nach Möglichkeit eine deutsche Stimme aus.

Je nach Gerät und gewählter Stimme kann die Sprachsynthese lokal auf dem Gerät oder über einen Online-Dienst des Geräte- bzw. Browserherstellers (z. B. Google oder Apple) erfolgen. Bei Online-Stimmen kann der vorzulesende Text dafür an den jeweiligen Anbieter übertragen werden. Darauf haben wir keinen Einfluss; es gelten die Datenschutzinformationen des jeweiligen Herstellers. Wenn du das vermeiden möchtest, kannst du in den Systemeinstellungen deines Geräts eine lokal installierte Stimme als Standard festlegen oder die Anwendung auf dem Desktop nutzen.

Die vorgelesenen Texte enthalten Spielabläufe und die von dir eingegebenen Spielernamen.

Löschen: Du kannst die gespeicherten Daten jederzeit selbst entfernen, indem du in den Einstellungen deines Browsers die Website-Daten löschst oder in den Entwicklertools den localStorage leerst.
